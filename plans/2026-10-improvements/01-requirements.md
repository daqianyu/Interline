# 大需求设计

## 产品目标与基线

把已有功能闭环的本地阅读 MVP 完善为可以长期使用的原生 iOS 27 阅读器。
优先级为资料可靠、阅读舒适、交互可发现、规模与效率，最后扩展功能。
本文件完整收录 2026-10-22 多角色审查的建议；它描述目标，不代表已经实现。

已确认的代码缺口、截图中的体验问题、待测风险和新增能力须分别处理。
尤其不能把“存在同步写入”直接表述成“真机已测得卡顿”，也不能将自动化通过
等同于发布完成。开发基线及状态见 `00-roadmap.md`。

## 产品经理视角

| ID | 问题/需求与方案 | 用户可验收的结果 |
|---|---|---|
| P01 | 新导入书籍的时间可能挤掉继续阅读；区分导入与真实阅读时间 | 导入未读书后，继续阅读仍指向原在读书；没有读过的书时显示合适的开始入口 |
| P02 | 草稿仅在数据管理中，不容易发现；在本书笔记中展示草稿及数量 | 取消编辑后，可从该书笔记继续原草稿；全局管理入口保留 |
| P03 | 进度到 100% 不等于用户读完；独立维护手动完成状态 | 跳到结尾不强制标记读完；支持标记读完和重新阅读，重启保持 |
| P04 | 大书架缺少组织与批量管理；增加集合、列表、批量移出和持久化排序筛选 | 多书整理无需逐个操作；移出仍可恢复；重启保持用户选择 |
| P05 | 发行材料与真实反馈闭环不足；补齐图标、版本、反馈、发布说明、签名分发验收 | 版本可识别、反馈可附诊断信息；取得签名后才标记真机安装通过 |

## 测试经理视角

| ID | 缺口与方案 | 验收目标 |
|---|---|---|
| Q01 | 内部导入/恢复测试不能替代真实文件流程；覆盖本地、iCloud、取消、不可用、空间不足 | 全流程有结果，失败不破坏原资料；区分模拟器和真机证据 |
| Q02 | 当前自动无障碍仅标签与类型；扩大到字体、对比度、触控、焦点和 VoiceOver | 主要功能在大字体及辅助操作下可独立完成 |
| Q03 | 缺少真机冷启动、峰值内存、长读和能耗基线；建立固定样本与测量步骤 | 报告环境、样本、分位耗时和内存；模拟器数字不冒充真机结论 |
| Q04 | UI runner 曾在启动阶段失败；分类环境与业务失败，留存证据 | 重跑有明确原因，业务失败不能通过无限重跑掩盖 |

## 架构师与开发者视角

| ID | 已知行为/风险与解决方向 | 验收目标 |
|---|---|---|
| D01 | 损坏书签/设置/阅读记录来自 UserDefaults，后续保存会覆盖；先封存原始键值，失败则拒绝替换 | 精确保留 Data 字节及其他属性列表类型；正常写入不制造无用副本 |
| D02 | 备份恢复 catch 忽略回滚结果，却声称原资料保留；区分成功回滚和待恢复 | 回滚失败保留日志、阻止后续写入、明确重试入口；不宣称已安全恢复 |
| D03 | 每次输入同步重写所有草稿；串行后台存储、合并写入、可见保存状态 | 输入无同步大文件写入；顺序正确，离开/后台刷新，失败保留输入 |
| D04 | 完整备份全量加载编码后才限 256 MiB；预检、逐书处理和文件式格式演进 | 大小限制前置，峰值可测，v1 可读，新版可恢复，不误称无限容量 |
| D05 | 从管理页保存草稿可能主线程解码整本书；异步获取目标章节 | 保存期间界面可响应，取消及切换不会写到其他章节 |
| D06 | 详情/导出等错误仍依赖全局提示，可能被 sheet 遮挡；统一页面内反馈与重试 | 用户不退出当前页面即可看到原因、保持输入并重试 |
| A01 | AppState 承担多域且直接可写状态较多；拆分阅读会话、书库、笔记、维护边界 | 单一写入口，原行为/迁移测试不退化，不为拆分而重写工作正常的引擎 |
| A02 | 正文仍整书解码；依据 Q03 决定按章加载与索引 | 先有瓶颈证据，再落地按章方案；查找/书签/笔记锚点兼容 |
| A03 | 导入/回滚可留下未引用正文；增加引用核对和可审查清理 | 不误删活动、已移出、待清理或恢复所需内容；失败可重试 |

## 用户视角：关键好用功能

| ID | 方案 | 体验边界 |
|---|---|---|
| F01 | 导入标准无 DRM EPUB，读取书名、作者、封面、目录和正文 | 加密、不支持的排版、损坏压缩包明确报错；不执行书内脚本或远程资源 |
| F02 | 从系统“打开方式”进入应用，复用导入预览 | 外部 URL 生命周期与权限正确，重复内容不重复建书 |
| F03 | 批量导入队列，逐项进度、取消和结果摘要 | 一项失败不撤销已成功项；重试只处理失败/取消项 |
| F04 | 分页之外增加连续滚动，支持单手阅读 | 两模式共享稳定位置；切换、旋转、重启不跳失 |
| F05 | 舒适/紧凑/大字预设，一键恢复默认，按书偏好 | 区分全局默认和本书覆盖；调整不改变书签、笔记 |
| F06 | 全局笔记入口、搜索、按章节整理、带书名章节信息的导出 | 原文跳转准确；已移出书的笔记仍可找到，永久删除语义一致 |
| F07 | 导入/备份进度和结果；恢复前列新增、保留、冲突；允许明确的部分导出 | 单书损坏不必阻断其余资料导出，但必须列缺失项，绝不标“完整备份” |
| F08 | 继续阅读小组件，使用实际阅读记录 | 点击进入正确书及位置；共享数据最小化，不暴露私人笔记 |
| F09 | 系统朗读与睡眠定时 | 暂停/恢复/音频中断正确；计时结束停止；后台与能耗必须真机验收 |

## iOS 27 开发者与设计者视角

保留 SwiftUI、原生文件选择器和官方 Liquid Glass。原生控件优先，
工具栏优先级/溢出能力以实际 Xcode 27 SDK 编译为准，不直接照搬未验证 API。
内容层保持稳定底色，玻璃用于导航与操作层，避免多层叠加和长期遮挡正文。

| ID | 当前不足 | 解决方案与效果 |
|---|---|---|
| U01 | 搜索/笔记/书签整行继承按钮蓝色，主次不清 | 正文主色、说明次色、操作强调色；搜索词独立强调，所有阅读主题核验 |
| U02 | 书架四个顶栏入口；数据管理藏在筛选图标中 | 保留主要导入操作；系统搜索；更多菜单以明确文字呈现管理功能 |
| U03 | 固定玻璃栏，返回、进度、操作区域零散 | 合并有层级的控制区，次要操作溢出；窄屏/横屏/大字可用，收起还原阅读 |
| U04 | 设置长而混杂，半屏看不到常用项 | 首屏常用字号、字体、背景和预设；高级参数分组；效果预览与重置 |
| U05 | 双换行叠加段间距，视觉留白偏大 | 统一呈现段距；不直接改 canonical text；所有 UTF-16 锚点保持 |
| U06 | 长按后需要再次选择；“本段”实际是页首段/片段 | 短期改准文案；中期触点映射预选段落，逐步原地选择，保留跨旋转快照 |
| U07 | 固定小字号、部分按钮未扩命中区、布局硬编码 | 使用语义字号/缩放，目标至少 44×44 pt；最大字号自适应，焦点和对比度合格 |
| U08 | “宋体”仅请求系统 serif，中文字形未明确保证 | 核实实际中文回退字体；采用准确名称或明确字体选择 |
| U09 | 深色纯色封面辨识度不足 | EPUB 原封面/用户封面优先；TXT 用克制配色和清晰书名字体，不加入装饰噪声 |

## 约束与成功标准

- 维持本地优先、iOS 27、SwiftUI、原生交互，无新增账号/网络业务。
- 既有备份、书签、笔记和阅读位置兼容；任何迁移必须先写兼容与失败方案。
- 大功能在进入实施前补充边界和具体测试数据；尚未完成时保持 TODO，不放空按钮。
- 发行验收需满足所有本轮发布范围项及签名真机条件。P3 可独立后续发布，
  必须在验收记录中明确范围，不能悄悄丢弃。
